# AFD Customer Portal — Demo

Static demo of a client load-tracking portal for Advanced Freight Dynamics LLC (USDOT 1876629 · MC-620040).
All customers, loads, names and numbers are sample data.

Screens: `#/login`, `#/dashboard` (live map of all active loads + Needs your attention), `#/load/AFD-25104` (map, progress,
site checklist, activity, load & permits, photos, documents, messages, alerts), `#/track/AFD-25104` (read-only link for site crews),
`#/yard` (Big Spring Terminal storage), `#/history`, `#/quote`.

AFD plans and secures the permits. Each state assigns the route.
